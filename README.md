# Oshi Extension: Librus Synergia

[![Oshi Compatible](https://img.shields.io/badge/Oshi-Extension-7c3aed.svg)](https://github.com/Ogaku/Oshi)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Official register provider extension for [**Librus Synergia**](https://synergia.librus.pl) in [**Oshi**](https://github.com/Ogaku/Oshi).

## Features
- Timetable & substitution sync
- Grades & averages
- Announcements & school timeline
- Messages & homework tracking

## Installation in Oshi
1. Open **Oshi**.
2. Go to **Settings > Manage Extensions** (or during the initial setup).
3. Search for **Librus Synergia** or install directly via URL:
   `
   https://raw.githubusercontent.com/Ogaku/Oshi-Extension-Librus/main/extension.dart
   `
4. Enter your Synergia credentials and enjoy!
